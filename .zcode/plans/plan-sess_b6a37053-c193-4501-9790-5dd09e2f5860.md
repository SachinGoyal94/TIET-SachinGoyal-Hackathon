## Tech Stack (keyless by design)
- **Engine:** FastAPI + Uvicorn, SQLAlchemy + SQLite (file on mounted volume), APScheduler
- **NLP (local models):**
  - Sentiment: `ProsusAI/finbert` → P(pos)−P(neg) ∈ [−1, 1]
  - Event classification: small zero-shot NLI model (`typeform/distilbert-base-uncased-mnli`) + keyword lexicon + GDELT CAMEO-code blending; labels: Geopolitical, Macroeconomic, Credit Event, M&A, Product Launch, Other
  - Impact score 1–10: explainable composite — base severity per event type × sentiment extremity × source count (event clustering) × recency; formula documented
  - Entity matching: alias table text → S&P 100 tickers / sectors / sovereigns (fast, no heavy NER)
- **Data sources:** GDELT DOC 2.0 API (keyless), vendored Kaggle "Sentiment Analysis for Financial News" sample + synthetic news/tweet generator (attribution noted in README), yfinance for market data (cached to disk so the demo survives offline)
- **Dashboard:** Streamlit, 4 tabs — Overview | Risk Engine (live signal table + paste-text analyzer) | Module A (weights over time, deltas, index NAV) | Module B (portfolio, trigger panel, before/after stress, waterfall, risk indicators)

## Module design
- **Module A:** universe of ~14 S&P 100 tickers; market-cap anchor weights from yfinance; per-ticker decayed sentiment aggregate → target weights = (1−α)·anchor + α·softmax(β·score), with 20% per-stock cap, sum=1, 2% turnover cap per rebalance. History stored; dashboard shows stacked weights over time + current deltas.
- **Module B:** synthetic portfolio (~40 positions: corporate/retail loans with ratings & spreads, govt/corporate bonds with duration, derivatives with delta). Shock matrix per event type × impact band (e.g., Geopolitical impact>7 → equities −10%, rates +200bp, spreads +150bp, scaled by impact). Repricing: duration/convexity for bonds, spread+PD bumps for loans, linear greeks for derivatives. Auto-triggers from engine events; before/after values, P&L per asset class, top losers, risk indicators.
